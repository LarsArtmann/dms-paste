# Domain Language

Ubiquitous-language glossary for dms-paste. Terms are ordered by where you
meet them: plugin behavior first, then module/patcher vocabulary.

| Term                               | Definition                                                                                                                                                                                                                                    | Where used                                                     |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Snippet                            | One `.txt` file in the snippets directory; filename (minus `.txt`) is the name, file content is the payload.                                                                                                                                  | `plugins/snippets/SnippetsLauncher.qml`, README                |
| Snippets directory (`snippetsDir`) | Directory holding snippets, default `~/.local/share/snippets`; literal `~/` is expanded by the plugin at runtime.                                                                                                                             | `module.nix`, `SnippetsSettings.qml`                           |
| Trigger (`:s`)                     | The launcher prefix that routes a spotlight query to the snippets plugin.                                                                                                                                                                     | `plugin.json`, `SnippetsLauncher.qml`                          |
| Save mode                          | Query form `:s > name`: captures the live clipboard into a new snippet (chmod 600).                                                                                                                                                           | `SnippetsLauncher.qml` `getItems`                              |
| Delete mode                        | Query form `:s -name`: lists matching snippets; Enter trashes the file (recoverable).                                                                                                                                                         | `SnippetsLauncher.qml` `getItems`                              |
| Recents                            | Last-used snippets (max 10) sorted first in results. Session-scoped while the upstream state writer is broken.                                                                                                                                | `SnippetsLauncher.qml` `recentFiles`                           |
| Paste synthesis                    | Making the focused window receive the snippet: copy into the DMS clipboard (`dms cl copy`), let the launcher close, then synthesize Ctrl+V (`dms cl send-paste`) over the compositor's virtual-keyboard protocol. Never wtype/ydotool/uinput. | `SnippetsLauncher.qml` `pasteCommand`, AGENTS.md               |
| Direct paste                       | Enter/click on a clipboard-history entry pastes it immediately (instead of only copying). DMS implements it; this repo's module just wires the defaults.                                                                                      | `module.nix` `clipboardEnterToPaste` / `clipboardClickToPaste` |
| PasteBot parity                    | The behavioral baseline inherited from PasteBot (macOS): snippets with recents, direct paste, dense clipboard UI. Encoded as `mkDefault` values, not mandates.                                                                                | README, `module.nix`                                           |
| Framed scan                        | The async directory scan: `sh` emits records framed with `\x1e` (record) and `\x1f` (field) so arbitrary multiline content round-trips; oversized files emit a `TOO_LARGE` marker with size instead of content.                               | `SnippetsLauncher.qml` `scanProcess`                           |
| Plugin contract                    | The DMS launcher-plugin API this repo implements: `getItems(query)`, `executeItem(item)`, `getPasteArgs(item)` (Shift+Enter path).                                                                                                            | `SnippetsLauncher.qml` header comment                          |
| Drift guard                        | A post-patch `grep -q` assertion in `patch.nix` (plus a negative guard where a surviving match alone is weak evidence) that fails the build when upstream QML text has drifted past a patch anchor.                                           | `patch.nix`, `flake.nix` `patch-contract`                      |
| Patch anchor                       | The exact upstream QML text a sed/perl leg rewrites (e.g. `property int modalWidth: 650`). Anchors are verified against upstream-shaped fixtures in `tests/fixtures/`.                                                                        | `patch.nix`, `tests/fixtures/`                                 |
| `mkDefault` baseline               | Every setting the module assigns uses `lib.mkDefault`: the repo ships defaults, consumers override without fighting merge priority.                                                                                                           | `module.nix`                                                   |

No deprecated terms. No bounded-context splits — the vocabulary is uniform
across plugin, module, and patcher.
