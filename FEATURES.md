Honest inventory of what this repo ships. One row per user-visible feature.

**Verification basis:** the nix checks (`nix flake check`) contractually exercise the HM module wiring (`module-contract`), every `patch.nix` drift guard over upstream-shaped fixtures (`patch-contract`), the plugin's pure logic (`plugin-logic`, node tests over the exact `SnippetsLogic.js` the QML imports), and QML parse validity (`qml-preflight`, qmllint with type resolution disabled); CI runs the same on every push. QML/Quickshell semantics beyond parsing has no automated tests here; FULLY_FUNCTIONAL for integration rests on daily-driver use in SystemNix before extraction (2026-10-16, see provenance in AGENTS.md).
